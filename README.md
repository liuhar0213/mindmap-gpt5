# MindMap GPT5

一个基于 Tkinter 的桌面思维导图工具，提供主流思维导图软件常见甚至进阶的操作：可自定义快捷键、自动排版、颜色与背景定制、节点备注、快速搜索、撤销/重做、附件、导出等能力。

## 功能特性

- 以中心节点为根的树状导图，支持拖拽节点保持相对位置不变
- Tab / Enter / Ctrl+Enter 一键生成空白子节点或兄弟节点，直接在画布上编辑文本
- 节点支持复制/粘贴、颜色标签（256 色调色板 + 自定义）、备注、附件、撤销/重做与自动排版
- 通过搜索框或 `Ctrl+F` 快速定位节点（标题或备注）
- JSON 文件保存/加载思维导图，向下兼容旧版本数据
- `Ctrl` + 鼠标滚轮随意缩放，右侧工具栏可通过拖动分隔条随意伸缩
- 支持设置画布背景色、按层级展开/折叠节点、自动保存与 Markdown/文本/JSON 多格式导出
- 全局快捷键可在“设置 → 快捷键设置”中随时修改并自动保存

## 环境要求

- Python 3.11+
- 依赖标准库，无需额外安装第三方包

## 快速上手（适合小白）

1. **安装 Python**：访问 [python.org](https://www.python.org/downloads/) 下载最新版，安装时勾选“Add python.exe to PATH”。
2. **获取项目文件**：点击 GitHub 页面右上角绿色的 `Code` 按钮选择 `Download ZIP`，解压到任意文件夹。
3. **打开命令行**：
   - Windows：在解压后的文件夹地址栏输入 `cmd` 回车。
   - macOS：在“终端”中使用 `cd` 切换到项目文件夹。
4. **启动程序**：输入以下命令并回车：

   ```bash
   python -m mindmap.app
   ```

   成功后会弹出一个窗口，中央自动生成一个空白根节点，直接双击即可输入标题。

   > 如果命令行提示 `ModuleNotFoundError`，可以改用 `python mindmap/app.py`（Windows 资源管理器双击 `mindmap/app.py` 也可启动）。

## 界面操作指南

界面左侧是思维导图画布，右侧是工具栏（可通过拖动中间分隔条调整宽度）：

- **选择节点**：鼠标左键点击即可选中，被选中的节点会出现高亮边框。
- **拖拽排版**：按住节点拖动即可改变位置，父节点与所有子节点会保持相对排布。
- **缩放视图**：按住 `Ctrl` 并滚动鼠标滚轮即可放大或缩小画布。
- **快速搜索**：右侧输入框或 `Ctrl+F`，根据节点标题与备注实时高亮匹配结果。
- **直接编辑**：双击节点或按 `F2` 即可在画布上编辑文本，不再弹出对话框。
- **颜色标签**：在“颜色”区域可选择 16×16 共 256 个色块，或点击“更多颜色”使用系统拾色器。
- **节点备注**：在底部的“备注”输入框中编写详细说明，失去焦点即自动保存。
- **自动排版**：点击“自动排版”按钮或按 `Ctrl+L`，系统会按照树形结构重新布局。
- **层级控制**：侧边栏或菜单中的“展开到指定层级”可限制显示深度，“展开全部”可恢复完整视图。
- **插入附件**：选择节点后点击“插入文件”或在右键菜单中选择，将本地文件与节点绑定。
- **打开/移除附件**：使用侧边栏按钮或右键菜单即可打开或解除绑定，节点下方会显示 📎 图标提示。
- **自动保存**：所有编辑操作都会定时自动保存至当前文件；若未保存过，会在用户主目录生成 `.mindmap_autosave.json` 以便恢复。
- **背景自定义**：在侧边栏或“工具”菜单中选择“更改背景颜色”，即可快速切换画布风格。
- **快捷键自定义**：打开“设置 → 快捷键设置…”，即可为任意动作重新录制快捷键或恢复默认。

### 常用快捷键

| 操作 | 默认快捷键 |
| --- | --- |
| 新建导图 | `Ctrl+N` |
| 打开导图 | `Ctrl+O` |
| 保存导图 | `Ctrl+S` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 添加子节点（空白并直接编辑） | `Ctrl+Enter` |
| 添加兄弟节点（空白并直接编辑） | `Shift+Enter` |
| 快速子节点（空白） | `Tab` |
| 快速兄弟节点（空白） | `Enter` |
| 复制 / 粘贴节点子树 | `Ctrl+C` / `Ctrl+V` |
| 重命名节点（画布内编辑） | `F2` |
| 删除节点 | `Delete` |
| 自动排版 | `Ctrl+L` |
| 搜索节点 | `Ctrl+F` |
| 画布缩放 | `Ctrl` + 鼠标滚轮 |

> 所有快捷键都可以在“设置 → 快捷键设置…”中自定义或清除。

## 保存、附件与导出

- **保存**：点击工具栏的“保存”按钮，选择一个文件夹后输入文件名，会生成 `.json` 文件。
- **打开**：点击“打开”按钮，选择之前保存的 JSON 文件，导图会自动加载。
- **自动保存**：编辑后无需手动保存，程序会在 1.5 秒内自动写回当前文件；若尚未手动保存，会将最新进度保存在用户主目录的 `.mindmap_autosave.json`，下次启动会提示恢复。
- **导出**：通过菜单“文件 → 导出”可以生成 Markdown、纯文本或额外的 JSON 副本，便于分享或二次处理。
- **附件**：每个节点都可绑定一个本地文件，绑定后会显示 `📎` 图标，并可在侧边栏或右键菜单打开或移除附件。
- **示例数据**：项目提供了 `examples/getting_started.json`，导入即可看到一个简单的示例导图。

> 提示：JSON 文件是纯文本格式，可以用记事本等编辑器打开查看，但请避免随意修改结构，以防出现加载失败。

## 常见问题

- **窗口打开后没有显示中文？**
  - 默认根节点名称是英文，可通过重命名改成任意文字。
- **命令行提示 `python` 不是内部或外部命令？**
  - 说明 Python 没有正确加入系统环境变量，重新安装时勾选“Add python.exe to PATH”即可。
- **保存时路径打不开？**
  - Windows 用户请确保对目标文件夹有写入权限，可尝试保存到“桌面”或“文档”。

如果仍有问题，可截图报错信息与当前操作步骤，方便进一步协助。
